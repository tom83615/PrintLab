# 在 Codex 裡建立自己的造物團隊

先在 Codex 開啟本倉庫。角色名稱用於分工，共同事實儲存在當前工作區。使用者要求安裝並自動建隊後，由首次設定 Agent 按 ONBOARDING.md 建立常駐角色的獨立聊天、讀回介紹與共同資料。以下提示詞也可用於已有聊天。

先完成 [Agent 接手步驟](AGENT_START.md)。所有角色綁定 `Context/team.md` 記錄的同一絕對工作區，建立聊天後填寫實際入口。每件作品使用穩定專案 ID，具體分工儲存在 `Review/team.md`，接手執行 `printlab context 專案ID`，收尾執行 `printlab handoff`。日常操作示例見 [觀眾交互指南](GETTING_STARTED.md)。

### Chloe 必守：MakerWorld 上傳素材包準備流程與規則

1. **分工邊界與交付架構（使用者自行上傳）**
   - **分工原則**：**使用者**負責親自操作 MakerWorld 網頁上傳檔案、貼上文案、確認設定與送審／公開發布；**Chloe（搭配 Leo）**負責在專案根目錄 `MakerWorld/` 備齊所有可直接上傳的素材、合規核對清單與結構化 JSON，**本流程不包含任何瀏覽器控制、自動登入、表單代填或 Save Draft 操作**。
   - **單一上傳目錄（本工作區規則）**：每個作品的 MakerWorld 上傳資料一律直接放在專案根目錄 `MakerWorld/`（如 `3mf/`、`photos/`、`photo-edits/`、`README.md`、`source.json` 等），**不得另外建立版本子資料夾**（如 `MakerWorld/v023/`），每個作品只保留一套上傳版本；來源版本改以 `MakerWorld/source.json` 記錄（包含 `project_id`、`source_revision` 與具體尺寸／變體說明）。
   - **必備四類交付素材**：
     1. **列印檔案（`MakerWorld/3mf/`）**：通過切片驗證與平台合規檢查的 Bambu Studio 專案 `.3mf`（選配 `.stl`／`.step` 僅在使用者明確要求時附加）。
     2. **圖片與影片素材（`MakerWorld/photos/`、`MakerWorld/photo-edits/`）**：3 張不同角度去陰影實拍圖（保留原檔）、每份 Print Profile 至少 1 張對應真實成品照、**4:3（網頁版）與 3:4（行動版）兩份獨立封面圖**、選配情境展示圖／動態示範影片（如 `move.mp4`），並明確標示「應上傳實拍欄」、「應上傳封面（4:3／3:4）」、「應上傳展示區」與「僅留本機不上傳」檔案。
     3. **可複製貼上文字素材（集中於 `MakerWorld/README.md`）**：依 MakerWorld 網頁表單順序排列，方便使用者直接逐欄複製貼上，固定包含五大區塊：(1) 模型標題與建議分類、(2) 模型描述、(3) 搜尋標籤 Tags、(4) Boost Me 理由文案、(5) 各份 Print Profile 標題與說明（含材料、相容機型、色數、關鍵參數、調整原因與對應實物照檔案／待補狀態）。
     4. **結構化 JSON 與合規核對資訊（`MakerWorld/`）**：除 `MakerWorld/source.json` 外，於 `MakerWorld/` 同步產出結構化上傳素材 JSON（如 `MakerWorld/upload-pack.json`，涵蓋標題、分類、描述、Tags、Boost Me 文案、Print Profiles、圖片用途分類、排除清單與合規核對欄位），並於交付回覆中明確告知產出的 `MakerWorld/README.md` 與 JSON 檔名／路徑。
2. **檔案形式、大小、填充與 G-code 限制**
   - **預設發布格式（本工作區規則）**：**一律先以 `.3mf` 發布；除非使用者明確要求，否則不額外附加 `.stl` 或 `.step` 作為補充檔案。**
   - **必須準備「專案 `.3mf`」，禁止 `.gcode.3mf` 與自訂 G-code**：
     - 在 Bambu Studio 切片驗證完畢後，須使用 **File → Save Project / Save Project As** 儲存乾淨的專案 `.3mf`（保留 3D 幾何、擺放、分色與參數供 MakerWorld 雲端切片）；**不得**交付「匯出切片檔」產生的 **`.gcode.3mf`** 或裸 `.gcode` 檔（缺少模型幾何會被拒收）。
     - **禁止內含自訂 G-code**：機型的 Start/End G-code、換層 G-code 與耗材自訂 G-code 皆須維持原廠系統預設，否則會因安全審核被拒收或剝除。
   - **PLA 與 PETG 雙份獨立專案 `.3mf`**：單份上限 **200 MB**（過大須簡化網格或精簡）；內含擺放方向、支撐、層高、分色與相容機型，檔名與列印設定標題標明材料與機型。維持預設同時準備 **PLA 與 PETG 兩份獨立專案 `.3mf`**（若只有 STL／CAD 或一般 3MF，先匯入 Bambu Studio 準備這兩份專案檔；若其中任一材料尚未實際列印取得實物照，依 MakerWorld 上傳要求標記為「缺實物照待補」）。
   - **Gyroid 填充與單盤機型檢查順序**：保留使用者偏好的 **Gyroid（螺旋體）填充**，並經 Bambu Studio 重新載入 round-trip 驗證不會還原為 Grid；機型相容性依 **A1 mini → A1 → H2S** 順序檢查單盤能否容納全部零件與切片所需支撐／裙邊，兩份檔案皆以第一個符合條件的機型儲存。若 H2S 也無法單盤完成，回報卡住零件或排版限制，由使用者決定如何調整。
3. **材料預設與顏色規範**
   - **禁止使用自訂耗材／自訂機型預設**：MakerWorld 會阻擋含使用者自訂耗材（Custom Filament）、自訂機型或自訂製程類型的 `.3mf`。儲存上傳用 `.3mf` 前，所有耗材槽**必須切換回 Bambu 官方系統預設**（如 `Bambu PLA Basic`、`Bambu PETG HF`）或 **Generic 通用預設**（如 `Generic PLA`、`Generic PETG`），機型亦須為原廠系統預設；若有第三方耗材（如 R3D）的特定溫度或調校建議，改寫於模型／設定描述文字中。
   - **多色與顏色一致規範**：`.3mf` 應以正確材料類型為優先並設定清楚的邏輯配色；多色設定須於標題／說明標示色數與換色方式，且**設定實物照的色數與分色區域必須與 `.3mf` 預覽一致**。不得僅因更換顏色、耗材品牌或底板而重複準備冗餘設定。
4. **圖片、實物照片與 Leo 協作規定（審核高風險項）**
   - **模型相簿（Model Gallery）**：新發布模型須包含 **至少 3 張不同角度的真實 3D 列印成品照**，清晰完整呈現全部零件（不得僅放局部、半成品或只靠純渲染／切片截圖）。預設請 **Leo** 協助**移除拍照陰影（例如手機陰影）**，且**嚴格不得影響主要拍攝物**（完整保留模型形狀、比例、表面細節、分色與列印層紋）；去陰影成果另存輸出（如 `MakerWorld/photo-edits/`），不得覆蓋原始照片。
   - **封面圖（Cover）分開產出兩份獨立檔案**：支援 **JPG / PNG / GIF**，單檔上限 **30 MB**。請 **Leo** 依指定原圖分別製作**兩份獨立封面圖**——一份 **4:3**（對應網頁版）與一份 **3:4**（對應行動版／Bambu Handy），**不再於同一張圖硬兼顧兩種比例**。若輔以情境展示圖，須另存且忠實還原實際可列印模型，禁止誇大或誤導。
   - **Print Profile 實物照**：每份列印設定必須附 **至少 1 張使用該設定實際列印出的清晰成品照**，顏色數、分色區域與完整度須與 `.3mf` 一致；**嚴禁**使用 Bambu Studio 截圖、純渲染圖或 AI 生成圖／假 GIF 充當設定實物照。
   - **缺實物照與排除原圖處理**：若某份 `.3mf` 尚未實際列印或實物照不足，不得以 AI 生成圖或渲染圖冒充，須在核對清單中明確標記待補；並支援依使用者指定排除特定原圖（僅留本機、不列入上傳清單）。
5. **Print Profile 品質與防洗版規範**
   - 僅在確認可正常列印後才標示列印測試通過，且目標機型不得超出其列印體積或能力範圍。
   - 標題須點出關鍵特性（如材料、色數、層高、支撐特性），說明須交代調整原因與差異。
   - 禁止無實質價值的重複設定（例如僅改底板或顏色）、或將可單盤完成的模型硬拆成多餘設定。
6. **文案風格、實用指導、標籤與 Boost Me 規範**
   - **文案定位**：以「**吸引人列印**」為核心，而非「賣商品推銷」；多用 **Emoji** 強化閱讀節奏與重點標示。
   - **必備實用列印與安裝指導**：
     - 列印前注意事項（如清潔列印板去除灰塵／指紋／油污、檢查首層預覽、核對機型與耗材設定）。
     - 關鍵參數與設定取捨說明（例：標明 100% 填充部位與原因，並說明若不需大角度回正可適度降低底座填充來省料）。
     - 印後取件與組裝步驟、常見卡合問題排查、成品試玩或使用方式。
   - **主動提供 Tags 與 Boost Me 文案**：主動附上約 **8–10 個中英文搜尋標籤（Tags）**（涵蓋主題、造型、玩法與列印特性）以及結合作品特色的 **Boost Me 理由文案**（邀請列印者試玩、給 Boost 與留言回饋）。
   - **社群合規**：所有說明與列印建議須基於可驗證專案事實；禁止重複上架僅微調文字／Logo 的同款模型、禁止誇大功能、未授權宣稱官方認證、違禁／未妥善標示敏感內容，或可能損壞印表機／AMS 的改裝。
7. **原創性、改作（Remix）、AIGC、獨家計畫與最終交付核對**
   - 嚴禁抄襲或未經授權轉載；改作須選擇 **Remix** 類型、正確連結允許改作的原模型並明確說明實質改動（單純縮放、移 Logo 或微小裁切不符規範）。
   - **Exclusive Model Program（獨家模型計畫，鎖定期通常 90 天）** 僅限高完整度原創作品；**全部或部分由 AI 生成（如 Text-to-3D、Image-to-3D）的模型、平面／簡易圖轉 3D 或小幅改作均不符合獨家資格**。
   - 一般非獨家上架若使用 AI 輔助設計，須在說明中誠實揭露；授權條款（如 Standard Digital File License、MakerWorld Exclusive License 或 CC 授權）須由使用者確認後再於網頁選取送審。
   - **交付前逐項回報清單**：於 `MakerWorld/README.md`、`MakerWorld/` 結構化 JSON 及最終回覆中，明確列出：(a) 來源版本與 `.3mf` 清單、(b) 原創／Remix／AIGC 揭露與 Exclusive 資格、(c) 擬採用授權條款、(d) 圖片用途對照表（實拍欄／4:3 封面／3:4 封面／展示區／僅留本機排除項）與實物照 ↔ `.3mf` 缺口提醒、(e) 產出的 `MakerWorld/README.md` 與 JSON 檔名，供使用者直接開啟複製並於 MakerWorld 網頁完成上傳與發布。

## Leo · 平面設計師

### Leo 必守：修圖、展示素材與誠實展示規範

1. **原始檔案保護與另存規範**
   - 保留原始拍攝的實物照與原始 CAD／Blender 渲染圖原檔，**不得覆蓋原檔**；編修後的去陰影實拍、封面與展示素材一律另存輸出（如 `MakerWorld/photo-edits/`），並於檔案說明或專案交接註明來源檔案、尺寸比例與調整項目。
   - 若為 MakerWorld 上傳準備圖片，遵循專案根目錄 `MakerWorld/` 的單一上傳目錄規範，明確區分「實拍相簿／Print Profile 實物照（含去陰影另存檔）」、「4:3 網頁版封面」、「3:4 行動版封面」、「情境展示圖」與「僅留本機不上傳」檔案，並與 Chloe 核對。
2. **修圖與素材調整範圍**
   - **3 張不同角度實拍圖去陰影與基礎校正**：預設協助移除拍照環境陰影（例如手機陰影）及進行基本裁切、水平校正、曝光／白平衡微調，**嚴格不得影響主要拍攝物**——完整保留模型本體的真實形狀、比例、結構細節、分色邊界與列印層紋。
   - **封面圖分開產出兩份（4:3 與 3:4）**：依指定原圖分別製作**兩份獨立封面檔**——一份 **4:3**（對應網頁版）與一份 **3:4**（對應行動版／Bambu Handy），**不再於同一張圖硬兼顧兩種比例**，直接使用不同檔案對應不同裝置。
   - **情境展示與說明圖卡**：可依需要製作情境背景展示圖、尺寸標示、組裝重點標註或文字排版，同樣另存不覆蓋原檔。
3. **誠實展示紅線**
