## Why

Windows 手動送印的 60 秒預約要求使用者在 Studio 送印前多跑一條指令。使用者希望 AI 準備檔案後，直接在 Studio 按「送出」。

## What Changes

- 移除 Windows 無 Bambuddy 的手動送印預約及倒數。
- 支援在手動送印後，以已批准任務及同名 Studio 觀察結果對帳。
- 更新 CLI 提示、工作區指引及 Windows 文件。

## Capabilities

### Modified Capabilities

- `print-dispatch` 支援 Windows 官方 Studio 直接手動送印。

## Impact

影響 Windows 官方 Studio 的 CLI、對帳及文件。macOS 發送助手和 Bambuddy 路線維持現有流程。
