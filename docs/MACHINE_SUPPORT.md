# 機型與驗證範圍

本表對應觀眾版候選程式碼。軟體驗收日期為 2026-11-13。

| 設定 | 已取得的證據 | 仍需現場驗證 |
| --- | --- | --- |
| A1、A1 mini、P1S、X1 Carbon，0.4 mm，PLA，紋理 PEI | 本機正常 CLI 建立專案、CadQuery 構建、Blender 真實預覽、官方 Studio 切片、獨立刀路檢查通過 | Bambuddy 佇列接受、符合設備作業、實際首層與成品 |
| X2D，0.4 mm，單主料 AMS | 既有官方模板檢查、Mac Studio 助手與發送保護迴歸通過 | 新候選版遷移後具體作業的現場驗收 |
| 其他型號、噴嘴、外掛或多噴頭組合 | 可以讀取已安裝官方設定；具體發送能力由預檢報告 | 對應設定的切片、供料和現場驗收 |

`trial_only` 表示這份切片仍缺當前列印設定確認。`printer_contacted: false` 表示該驗證過程未聯繫實體印表機。獨立文件檢查通過後，仍需當前設備、材料和具體任務批准。

Mac 和 Windows 使用同一佇列介面實現。候選版雲端結果、真實宿主和實體設備結果分別記錄，舊版本 CI 結果不能作為當前提交的驗證證據。工作台當前可用路線以“待列印”預檢中的通道能力為準。

新機型錄入包括型號、韌體、噴嘴、列印板、AMS/外掛實際連接、可用材料和網路使用方式。設備支援的軟體選項從安裝的官方 Studio 設定讀取，現場已裝配件另按讀回或使用者確認記錄。

首次接入與實際列印步驟見 [首次設定](ONBOARDING.md) 和 [發送指南](PRINTING.md)。
