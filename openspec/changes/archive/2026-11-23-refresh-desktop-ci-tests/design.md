# Design

## Context

一般核准不要求逐任務清板確認。取消重印與簽名拒絕的歷史對帳仍接受含清板證據的既有核准記錄。

## Goals / Non-Goals

**Goals:** 讓桌面 CI 以現行契約測試正常流程、拒絕分支及歷史記錄。

**Non-Goals:** 修改送印行為、設備檢查或歷史記錄格式。

## Decisions

- 用明確的既有記錄資料覆蓋歷史清板證據路線，另驗證現行核准在無該證據時維持阻擋。
- 一般模擬設備預設已就緒，另以待清板遙測驗證阻擋。
- 依現行回應檢查確認事實、作業狀態和配置訊息，保留防重送與防重複啟動的斷言。

## Risks / Trade-offs

本機 Windows 的符號連結權限可能與 CI 有差異。適用時以支援該功能的環境確認，並標記實際無法執行的測試。
