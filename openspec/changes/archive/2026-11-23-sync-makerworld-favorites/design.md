## Context

靈感收藏頁目前直接讀取 `Library/References/favorites.json`。Studio 服務已有隨 FastAPI 生命週期啟動的背景讀取工作。

## Goals / Non-Goals

同步範圍為帳號自己的收藏夾與模型。列印與 MakerWorld 內容寫入留在各自原有入口。

## Decisions

- 透過本機 CLI 隱藏輸入帳號憑據並執行首次同步。使用指定地區的唯讀請求，禁止重新導向。獨立的本機連線避免借用既有工具的登入資料。
- 使用社群已驗證的 MakerWorld 收藏夾查詢及模型分頁介面。頁面資料已含模型基本資訊，能減少逐件查詢。
- Studio 每小時同步一次，CLI 可主動更新。私有執行目錄存放上次成功快照，使用既有鎖與原子 JSON 寫入。工作台以專用 API 合併本機收藏和遠端快照。

## Risks / Trade-offs

- 上游介面沒有公開相容性承諾。回應格式或授權異常時保留舊快照並顯示狀態。
- 中國站網頁閘道會對非瀏覽器請求要求驗證。中國區使用同區 Bambu Cloud 介面，帳號驗證時確認該介面的實際回應。
- 帳號站點、登入憑據和收藏覆蓋需由實際帳號核對。正式版透過現有固定版本部署流程上線。
