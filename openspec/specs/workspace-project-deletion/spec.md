# workspace-project-deletion Specification

## Purpose

讓使用者從工作台移除指定的本機專案。清理前核對明確確認的專案編號與列印狀態，並保護其他專案、共享記錄和專案外的來源檔案。

## Requirements

### Requirement: 確認專案身分後刪除

工作台 SHALL 顯示專案名稱和編號，並要求使用者明確確認。刪除 API SHALL 驗證同源會話、CSRF 憑證和相同的專案編號。

#### Scenario: 使用者確認刪除

- **WHEN** 使用者透過工作台確認刪除且專案與其任務允許清理
- **THEN** 移除指定專案及其待列印、購物需求與快取關聯，保留其他專案、共享記錄、外部原始檔和歷史列印記錄

#### Scenario: 取消或編號不符

- **WHEN** 使用者取消或請求未通過會話及身分檢查
- **THEN** 專案維持原狀

### Requirement: 保護進行中的任務和專案外資料

清理流程 SHALL 檢查進行中及結果不明的任務，並將刪除範圍限制在已確認的專案與其關聯。

#### Scenario: 仍有進行中或待查證的任務

- **WHEN** 專案有執行中任務或發送結果待核對
- **THEN** 工作台阻擋刪除並顯示原因

#### Scenario: 專案內有指向外部的連結

- **WHEN** 專案內的符號連結或目錄接合點指向外部
- **THEN** 清理連結時保留其外部目標
