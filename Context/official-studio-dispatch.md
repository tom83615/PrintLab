# 官方 Bambu Studio 發送

首次使用先讀 `docs/PRINTING.md`，核對本機軟體版本、語言、機型、材料和發送助手的支援範圍。

1. 讀取任務交接、當前版本、已有派發回執與設備狀態。遇到未決任務先對賬。
2. 確認當前模型/切片/材料與使用者的列印要求一致，記錄當前清板事實。
3. 使用 `printlab studio-copy --help` 從未發送任務生成單盤官方發送包，儲存工具路徑和文件比對。
4. `printlab approve` 綁定具體文件、設備和材料。保留實際確認時間。
5. 用官方 Studio 開啟這份唯一任務名的包，核對切片預覽、機型、板型、噴嘴與 AMS 映射。
6. `printlab submit` 預檢，通過後 `submit --execute` 預約同一個任務，Agent 在返回的有效視窗內點選一次發送。
7. `printlab reconcile` 讀回符合任務，另外核實實際出料和首層。超時或結果不明時先查詢設備。
8. 完成後登記實物回饋，下一盤需要重新取件清板。

工作台“待列印”頁通過專用 macOS 發送助手執行時，同樣使用這套文件綁定、批准、鎖與回執。首次使用者需要為自己的機器構建並授權發送助手。內置能力檢查根據實際環境返回可用範圍。
