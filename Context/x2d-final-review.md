# 最終制作 Review

模型完成後，在同一次 Review 中核對品質、可靠性和總成本，使用 `Templates/Project/Review/x2d-final-review.md`。

1. 對照已確認外形、介面、握感與表面要求。
2. 核對本機噴嘴、材料、AMS/外掛、板型和切片設定。
3. 比較擺放方向、按顏色/高度分件分盤、支撐接觸層與同層換色次數。
4. 評估雙噴嘴、異材支撐和局部層高對當前模型的收益。相容性須有材料依據。
5. 候選實際切片，統計全套時間、主料、支撐、沖刷、換盤與後處理。等人換盤的時間未知時註明。
6. 儲存選擇理由、來源文件 hash、預計結果與仍需實物檢查的部位。

以設備實際支援為準。單噴與雙噴的收益需要針對具體任務比較。多噴嘴能力不代表每件作品都適合多材料。
