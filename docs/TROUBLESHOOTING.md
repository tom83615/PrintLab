# 列印與接續排障

先執行 `printlab --help`，用實際專案 ID 和任務 ID 讀取 `context`、`status`、`materials` 與 `reconcile`。保留錯誤原文、切片 SHA、韌體、通道和時間。下列經驗來自現有 PrintLab 工作流及本輪集成驗證，按適用條件使用。

| 現象 | 先核對 | 處理與完成證據 |
| --- | --- | --- |
| 工作台能開啟，設備連不上 | Bambuddy 是否在線、設備 ID、網路路線、憑據權限、局域網可達性 | 按連接指南選擇符合原有 Handy/Studio 使用習慣的路線，讀回設備身分、連接和新鮮狀態 |
| 安裝後 Handy、收藏或雲端行為改變 | 當前網路模式與安裝前方式、Agent 是否誤改權限 | 按使用者原需求恢復連接設定。舊雲端歷史和帳號收藏匯入已移出範圍，本機匯入與後續記錄繼續使用 |
| 啟動被拒絕或有 HMS 錯誤 | 錯誤碼、韌體、當前通道、是否已有任務 | 儲存原始回執，按實際錯誤處理認證或設備問題，重新讀狀態。需要改設備設定時由使用者作出相應選擇 |
| 設備顯示進度但未正常出料 | 實際載料順序、首層前最後升溫指令、切片材料和噴嘴映射 | 重新生成並檢查新切片，保留舊失敗包。使用者觀察實際首層，記錄是否出料 |
| 發送超時、頁面斷開或按鈕重複點選 | `dispatch.json`、唯一佇列 ID、設備任務名、狀態時間 | 先 `reconcile` 查原任務。已嘗試啟動的任務保持單次發送，結果未明時繼續查證 |
| 發送助手提示系統彈窗遮擋 | 當前桌面的螢幕讀取確認提示、輔助功能和螢幕讀取授權 | 使用者處理系統提示，再核驗視窗。權限探針為 true 時仍可能出現系統確認；發送結果以任務回執和設備讀回為準 |
| 發送助手找不到“關閉”或無法核驗選項 | Studio 版本、介面語言、實際截圖分辨率、按鈕識別結果 | 保留具體錯誤與視窗證據。低密度截圖重採樣正在實測，合併或低置信度按鈕會停止操作；Agent 修復適配後重驗完整任務資訊 |
| 上一盤取消後仍顯示 FAILED | 舊任務是否確實取消、設備螢幕狀態、板面和加熱狀態 | 儲存取消證據。Bambuddy 清板只能處理其佇列條件，設備狀態另讀回；新任務使用新切片和具體批准 |
| 材料、顏色、噴嘴或板型不符合 | 實際槽位、料卷關聯、切片預設、現場噴嘴和設備卡 | 更正當前事實與映射，重做受影響切片和批准。未知餘量明確顯示未知，按預檢缺項補充事實 |
| Mike/Sarah 建立中斷 | 共同工作區、建立標識、宿主已有聊天及臨時 ID | 找回實際 thread ID，繼續登記和讀回介紹，避免重複建立 |
| 新會話不知道當前作品 | 穩定專案 ID、`latest_session`、brief 和 decisions | 讀取 `context 專案ID`，沿用最新版本與選圖，結束時儲存 `handoff` |

## 本輪修復過的集成問題

- 獨立檢查器曾固定使用 X2D。現在按切片的實際機型選擇檢查模型，四機型實際切片已驗收。
- 官方刀路中的 `T1000` 會切換廠商工具編號空間。單噴嘴溫度檢查現保留可確定的唯一物理噴嘴映射。
- CAD 獨立環境沒有工作台的鎖庫。列印空間現在由工作台讀取並作為構建輸入傳遞，避免讓 CAD 環境依賴整套工作台。
- Windows 角色讀回可能使用反斜槓或絕對路徑。登記時規範化為工作區內的相對路徑，並拒絕其他目錄。

## 把經驗留給其他會話

先在具體專案覆盤寫現象、設備/材料/版本、證據、採取操作、結果及適用條件。使用者偏好保留原話。確認可複用後，通過 `workspace note lessons` 追加共享經驗，攜帶來源、穩定請求標識和當前文件哈希。新的 Session 由 `context` 讀取同一記錄。

介面接通、任務被接受、首層正常、機器完成和實物驗收分別記錄。材料和零件效果由實物回饋補充。
