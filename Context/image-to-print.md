# 兩次選圖，再做真實模型

## 適用範圍

新設計和改變外形的改裝預設採用本流程。已有選擇接續使用，小幅尺寸、配色與局部修改按實際影響檢查。

1. 明確用途、尺寸、設備與材料約束，提供可比較的單張外形方案。
2. 使用者選一款，儲存所有候選、選中圖片、提示詞、來源、hash 和原話，列出必須保留的輪廓、曲面、開孔與比例。
3. 圍繞選定外形提供四套三視圖，每套預設正、右、俯，統一座標與比例。四套表達同一設計的空間解釋，逐套檢查不同方向和遮擋關係。
4. 使用者選一整套，儲存 `Review/design-target.json` 中的兩次選擇。發現不一致時展示具體問題並修正。可用低細節空間草稿生成真實正交圖，標註推定的背面與內部結構。
5. 按選定目標建實際模型。原模型和實測尺寸約束配合介面，外形按已選目標推進。匯出同源三視圖、斜視與必要剖面，逐項檢查偏差。
6. 檢查介面、孔位、公差、壁厚、裝入路徑與承力，必要時先做同源試模。圖生網格作為外形候選處理。
7. 確認配色和材料，建立正式 3MF，完成製作 Review、切片與當前列印確認，列印後檢查實物。

## 改編已有模型

儲存原件、作者、連結、版本、說明與許可。建立受保護配合面、孔位、公差、卡扣/滑槽和拆裝路徑清單，可改外形區域單獨標註。每次修改檢查保護區與真實介面。公開分享時再逐件核對原許可。

## 命令與記錄

使用 `printlab design-check --help` 查看 input、views、release 檢查參數。模板位於 `Templates/Project/Review/design-target.json`。檢查關聯的文件、來源和 hash 後，仍要實際查看模型。選型歷史通過 `printlab taste record` 儲存，經驗寫入 `Context/taste.md`。
