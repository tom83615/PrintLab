# 第一次設定：先了解你的機器

由首次安裝 Agent 按 [可恢復設定流程](ONBOARDING.md) 讀取已有設定，已有明確答案不重複詢問。優先自動發現設備與材料，訪談補齊真實缺項，不能用作者的設備設定填空。

1. 使用 Mac 還是 Windows？Agent 是否能執行本機命令、讀寫文件、操作桌面？工作台準備長期放在哪個目錄？
2. 印表機準確型號、韌體版本，已裝噴嘴直徑和類型、列印板、AMS 數量與接線、外掛和 FTS 情況。
3. 現有材料的種類、顏色、具體產品、已裝槽位；未知餘量保持未知。是否有可用的專用支撐材料？
4. 電腦和印表機能否在同一網路通信？目前用雲連接還是 LAN Only？是否已使用 Bambu Studio、Bambuddy？是否需要保留 Handy 雲列印、帳號歷史和 MakerWorld 收藏？現有帳號使用國內站還是國際站？
5. 常做的物品、尺寸/強度/表面優先級、是否接受配件、多色耗時與耗料，以及支撐材料偏好。

把 H2C 設備事實寫入 `Library/Devices/H2C/device.json`，工具版本及驗證寫入 `Library/Devices/H2C/installed.md`，偏好寫入 `Context/profile.md`。未知欄位不寫成已驗證。IP、訪問碼和 API key 僅儲存在本機受限設定中，不寫入共享文件。

任務小組開始每件作品時讀取同一設備與材料記錄，並重新讀即時狀態。當前自動發送適配仍是 PRINTING.md 的特定 X2D/Mac 組合；填入其他機型並不會自動獲得切片與發送支援。

先記錄已有網路模式、雲登入、同步與 API key 的使用者。安裝工作台時沿用已有可用功能。需要更改網路模式或授權範圍時，先說明會影響的具體功能並取得使用者選擇。歷史與收藏驗收按 [同步排查](SYNC_TROUBLESHOOTING.md) 核對真實記錄。

## 每件作品的製造判斷

先確定用途、關鍵尺寸和驗收標準。新外形按 `Context/image-to-print.md` 選方案和同款視圖；功能件按 `Context/cad-master-design.md` 保護介面，試模與整件使用同一源幾何。小改動接續已確認決定。

最終 Review 比較擺放方向、分件/分盤、材料、支撐、噴嘴分工和換色開銷，計入所有盤、啟動、沖刷、換盤及後處理。優先品質和可靠性，不以減少壁厚或提高速度代替工程判斷。專用支撐是否適合由本機供料能力、材料相容性和使用者偏好共同決定，不能照搬作者的雙噴設定。

## 首次驗收記錄

分別記錄工作台、CAD、切片、設備讀取、發送助手的版本、實際命令、結果和缺口。沒有實際執行的步驟寫“未驗證”；模擬設備通過寫“模擬驗證”。安裝、建模和驗收不授權實體列印。
