# 觀眾怎樣使用 PrintLab

## 第一次把連結交給 Agent

在這臺電腦 上使用具有終端、文件讀寫能力的 Codex 或其他 Agent，把下面這段話發給它。

> 請幫我安裝 https://github.com/AFangTeam/PrintLab 。先讀取 README.md、AGENTS.md 和 docs/AGENT_START.md，在本機建立一個長期 PrintLab 工作區，安裝並啟動工作台，執行入門驗收。幫我建立 Sara · 3D 列印顧問和 Mike · 工作流設計師兩個聊天，全部綁定同一工作區，記錄實際建立狀態。第一件作品確定後再建立對應任務小組。缺少的工具按原作者渠道獨立安裝。需要我提供設備資訊、登入或選擇系統權限時，告訴我具體操作。最後給我工作區路徑、工作台地址、分工入口、已通過的驗證和下一步。

Agent 會下載倉庫，安裝工作台所需的軟體包，生成本機設定並開啟網頁。首次開啟通常是空專案和待連接設備。Agent 可繼續整理偏好和設備資料，逐項接入建模、圖像和列印工具。

通過瀏覽器查看倉庫的 Agent 需要本機執行工具才能完成安裝。聊天建立能力由宿主提供。宿主支援建立聊天時，Agent 可按上面的明確要求建立並核對。其他情況下，Agent 給出標題、提示詞和路徑，使用者在同一 Codex 工作區建立聊天。

## 日常在哪兒交互

| 想做什麼 | 操作入口 | 結果 |
| --- | --- | --- |
| 討論需求、發參考圖、修改尺寸和外觀 | Codex 任務小組聊天 | Agent 更新專案文件和設計版本 |
| 問機器、耗材、故障和配件 | Sara 聊天 | 更新設備知識、材料依據和購物清單 |
| 安裝工具、排查連接和修工作台 | Mike 聊天 | 更新本機設定及驗證記錄 |
| 看專案、模型、材料、歷史與交接 | PrintLab 網頁 | 查看當前工作區儲存的資料 |
| 用網頁整理新點子 | 點選“新想法”，填寫後點選“複製需求到對話” | 將需求貼上到任務小組聊天，由 Agent 建立專案 |
| 開始已準備的具體列印 | “待列印”中的任務核驗與啟動按鈕 | 使用當前設備狀態、清板確認和任務授權執行 |

網頁通過共享文件展示 Agent 的產出。聊天負責理解需求、使用工具和寫入專案。網頁的“新想法”操作會生成一段可貼上需求，完成貼上並由 Agent 執行後，專案才進入圖冊。

## Create your first object

在同一工作區新建聊天，命名為“任務小組 · 桌邊耳機掛鉤”，發送如下需求。

> 我想做一個桌邊耳機掛鉤。先建立 PrintLab 專案，記錄用途和需要測量的桌板厚度、可用空間、耳機重量。先完成需求整理，等我補充尺寸再進入外形方案。把需要 Sara 核對的材料與配件、需要 Mike 檢查的工具寫入專案分工，並把專案 ID 和圖冊入口告訴我。

Agent 會用 `printlab new` 建立資料夾，得到如 `P001` 的專案 ID，寫入需求與分工。回到網頁點選重新整理，在“專案圖冊”中開啟它，可以查看需求、文件和交接。專案剛建立時顯示“預覽待生成”。真實模型匯出後會出現相應預覽。

一次只做一件作品時，一個任務小組聊天就能推進所有階段。需要協作時，把同一個專案 ID 和具體問題交給 Sara 或 Mike。實際聊天入口寫入 `Context/team.md`，專案任務寫入該專案的 `Review/team.md`。

## 分工與交接怎麼銜接

給 Sara 的示例訊息如下。

> 請接手 P001，先執行 printlab context P001。核對這個掛鉤適合的現有材料、需要另購的配件和仍未知的條件，把結果寫入對應資料與 Review/team.md，再儲存交接。

給 Mike 的示例訊息如下。

> 請接手 P001，先讀最近交接。檢查本機建模和匯出工具，修復當前阻塞，記錄實際工具版本與驗證結果，隨後儲存交接。

回到任務小組時可以這樣說。

> 繼續 P001，讀最新 context、分工表和交接，沿用已確認尺寸與外形，從下一步繼續。

每個聊天都要指向同一個絕對工作區路徑。Agent 每輪結束使用 `printlab handoff`，下一輪讀取 `project.json.latest_session`。同一專案的正式版本由當前任務小組統籌，協作候選使用獨立目錄。

## 從設計進入列印

補齊需求後，按外形方案、三視圖選擇、實際 CAD、對照修改、配色、正式工程、切片比較逐步推進。Agent 會在需要審美選擇和實測資訊時向使用者展示結果。設備連接與材料映射核驗後，再對具體任務確認列印和清板。機器完成後，把實物照片、尺寸與使用回饋交給任務小組記錄。

工作台、角色分工、共享資料和專案接續可以從本倉庫建立。圖像生成、CAD、切片和實機發送的能力取決於本機獨立安裝的工具、帳戶權限、機型與材料。按接手指南逐項填寫已驗證狀態。詳細邊界見 [依賴說明](DEPENDENCIES.md) 和 [列印說明](PRINTING.md)。
