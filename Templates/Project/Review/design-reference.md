# 圖片與模型的設計約定

按 `Context/image-to-print.md` v3填寫。選定設計主圖與最初靈感圖必須分開；未知保留未知，不把AI補充視圖當作尺寸來源。

- 專案 / 候選版本：待填寫
- 已選設計主圖路徑及校驗值：待填寫；主圖不能因容易建模而換回最初靈感照片
- 靈感圖及用途：待填寫；不作為正式外形回退目標
- 機械介面/尺寸來源及保護區：待填寫；與外形目標分別管理
- 使用者選定依據 / 原話來源：待填寫
- 圖片性質：概念透視圖 / 實拍 / 由實際模型匯出的視圖（擇一）
- 需要保留的3–5項外形特徵：待填寫
- 關鍵尺寸與功能邊界：數值、單位、來源（實測 / 官方 / 使用者目標 / 暫定），待填寫
- 輔助圖片及用途：待填寫；不作為預設工程三視圖
- 四套同款三視圖：每套正/右/俯；儲存四套編號與文件/hash、使用者選定的一整套、每格裁剪和一致性檢查
- 主要孔洞/筋節點跨視圖對應表：待填寫；缺失面/推定結構標明
- `Review/design-target.json` 與 `printlab design-check` 結果：待填寫

## 實際粗模與後續依據

- 實際源文件 / 網格路徑、版本與校驗值：待填寫
- 同一實際模型匯出的對應三視圖（預設正 / 右 / 俯），必要背/底/斜視另作內部檢查：待填寫；必須另與已選主圖對照
- 相機與參考圖是否符合：未符合 / 近似 / 已配準；依據待填寫
- 未見面與內部的設計假設：待填寫
- 與主圖的已知偏差、下一步修改：待填寫
- 使用者對明顯取捨的選擇：未要求選擇 / 待選擇 / 已選擇（有真實記錄才填寫）

詳細外觀、尺寸及裝配檢查另用 `design-review.json`。圖片約定與外觀選擇不授權列印。
